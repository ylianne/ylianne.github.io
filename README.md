# Hossana Villanueva — GitHub Pages Portfolio

Minimalist-light responsive portfolio for the graduate-version Euthenics assignment.

## GitHub Pages target
- GitHub username: `ylianne`
- Repository: `ylianne.github.io`
- Website: https://ylianne.github.io (available after deployment)

## Personalize before publishing
1. Replace `assets/profile-photo-placeholder.svg` in `index.html` with your own portrait. Easiest: add your image as `assets/profile-photo.jpg`, then change the image `src` in `index.html` to `assets/profile-photo.jpg`.
2. The VeriSpace project card now displays your supplied QR code at `assets/verispace-qr.png`. Test the QR with a phone before submitting.
3. Replace the Jack's Kitchenette illustration by adding a screenshot named `assets/jacks-kitchenette-project.png` and updating the corresponding project-art block in `index.html` if you want to use a real screenshot.
4. Review the resume and application letter PDFs before making them public. The graduate resume is included as `Hossana_Villanueva_Resume_Graduate.pdf` and `.docx`.

## Publish
1. Create a **Public** GitHub repository named `ylianne.github.io`.
2. Upload the contents of this folder (not the enclosing folder) so `index.html` and `style.css` are in the repository root. Keep `assets/` and `documents/` folders.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for deployment and visit https://ylianne.github.io.

## Files
- `index.html`: portfolio content
- `style.css`: visual styling
- `assets/`: QR code, placeholders, and project art
- `documents/`: resume and application letter in PDF/Word formats

Note: the QR code is an image; it is not a clickable website link. Visitors can scan it using a phone camera.
